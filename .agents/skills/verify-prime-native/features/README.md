# Prime Native verification map

Read this index before driving the adapter. Use isolated configuration, runtime state, ports, and workspace for each run. Never drive the user's existing Prime daemon.

Record action and resulting state for each entry point. Keep terminal transcripts, HTTP requests, responses, and side-effect evidence outside the tracked tree. A skipped path remains a gap.

The default helper's local model fixture proves transport and living terminal reattachment. The adapter probe adds real kernel, resource, control, policy, and recursive-child scenarios. Neither fixture proves commercial provider login or model reasoning.

The disposable daemon probe executes real Python and tests public recovery commands separately. Its full gate failed on the tested Prime 0.9.6 artifact. It does not migrate or qualify the production extension adapter. Read the [probe workflow](../SKILL.md#disposable-daemon-qualification) before running it.
